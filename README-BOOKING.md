# Booking Demo - Portfolio Yassin

Booking demo for the Portfolio-yassin project.

## Current Status

Demo version only.

Technology:
- HTML5
- CSS3
- Vanilla JavaScript ES6+
- JSON
- LocalStorage

Not included yet:
- Laravel
- MySQL
- REST API
- Admin authentication
- Telegram Bot
- Online payments

## Pages

- `booking/index.html` — Booking page
- `booking/success.html` — Booking confirmation
- `booking/cancel.html` — Booking cancellation
- `admin/index.html` — Demo admin dashboard

## Data
