## 💻 Local Setup

This is a static HTML/CSS portfolio and does not require a backend server.

Clone the repository:

```bash
git clone https://github.com/Masterwebhosts/Portfolio-yassin.git
```

Open the project directory:

```bash
cd Portfolio-yassin
```

Then open:

```text
index.html
```

in your browser.
